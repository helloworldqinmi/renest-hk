# Technical review guide

Start at [the live demo](https://renest-hk.vercel.app/). The example requires no account, payment, camera permission or personal file upload. Use a desktop browser with WebGL for the full planning workspace.

## Suggested walkthrough

| Step | Action | Expected result |
| --- | --- | --- |
| 1. Capture | Choose **Start my move**, then **Scan my old home**. Use **Skip animation** if preferred. | The simulated capture resolves into 18 selectable furniture groups. |
| 2. Inventory | Inspect a furniture item and toggle whether to bring it. Continue with the selected pieces. | The selected count changes; dimensions remain attached to the same furniture identifiers. |
| 3. New home | Keep **Example floor plan** and the first library plan. Play the conversion and continue to the 3D home. | The supplied two-bedroom shell appears. The other library plans are reference previews. |
| 4. Brief | Choose **One-click smart move**, set a household, priority and furniture allowance, then **Show my arrangements**. | Three curated options expose different furniture and purchase trade-offs. Optional detailed needs refine these rules. |
| 5. Edit | Compare arrangements, switch to **Floor plan**, select a piece and use the move/rotate controls. | The placement changes in the shared plan. Basic fit warnings surface when a position is invalid. |
| 6. Handover | Inspect the report and download the moving CSV. | Furniture identifiers, destinations and estimates are available for human review. This does not book a carrier. |
| 7. Resume | Save a named plan, return home and open it from **Past arrangements**. | The arrangement restores in the same browser and origin. |

## What to evaluate

- **Decision clarity:** can a household see which furniture to bring, what fits and what it may need to buy?
- **Traceability:** do the inventory, selected arrangement and handover refer to consistent furniture identifiers?
- **Interaction:** can a reviewer compare, edit, save and revisit a plan without losing the current choices?
- **Logistics relevance:** could the structured furniture inventory and destination decisions support a future service handover?

Scanning, reconstruction and generative-style transitions are demonstrations. Layout selection and adaptation use local deterministic rules. Prices are illustrative; exports require human validation. See [product scope](product-scope.md) for the detailed boundaries.

## Repeating the review

Use **Start a new move** to restart the workflow. Existing saved arrangements remain in the browser. A fresh browser profile provides a clean first-visit experience without affecting existing plans. Storage is scoped to the deployment address, so plans saved on an old domain will not appear on the current one.

If the 3D view is unavailable, use a WebGL-capable browser and check whether hardware acceleration is enabled. If the hosted demo is unavailable, follow the [local setup](../README.md#run-locally). The [delivery package](../deliverables/README.md) provides optional presentation material; large MP4 files require download and local playback.

## Reproducing the engineering checks

From a Git clone with Node.js 24:

```bash
npm ci
npm run check
npm audit --omit=dev
npm run build
npm start
```

The delivery check uses Git to inspect tracked and ignored files. `next-env.d.ts` and route declarations are generated by Next.js; they are not source files to edit. Model generation and film authoring have separate tool requirements documented in their source directories and are not required to run the application.
