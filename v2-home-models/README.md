# ReNest V2 · 可迁移家具的两个家

独立的 3D 资产与预览网页，不修改现有 Next.js 网站。两套住宅结构、四个完整场景、22 件独立家具资产；所有尺寸均使用米，Y 轴向上。

## 查看

在项目根目录运行：

```sh
python3 -m http.server 4174 --bind 127.0.0.1 --directory v2-home-models
```

打开 http://127.0.0.1:4174/ 。请通过 HTTP 访问，勿直接双击 HTML。

- 顶部切换旧家 / 新家 A / B / C。
- 拖动旋转、滚轮缩放、右键平移；触屏支持双指缩放。
- **平面图与俯视均由当前 3D 场景的正交相机实时生成**，并保留当前家具布局与折叠状态，不使用原始平面图片代替。
- 完整墙体 / 剖切视图切换。剖切保留后侧高窗，降低前侧及隔墙以看清内部。
- 复用标记：绿色是旧家具，琥珀色是新增家具。
- 点击家具或侧栏清单，查看稳定编号、估算尺寸及来源。
- 「收起新家具」演示推车折叶、餐桌折叶、壁挂书桌的铰接状态；梯凳椅保留座椅形态，未模拟其完整变形机构。
- 下载当前 GLB、保存当前相机视角 PNG。
- URL 支持 `?layout=new-home-b&view=top`；`capture=1` 隐藏界面，便于输出纯模型图片。

## 四个场景

| 场景 | 沿用旧家具 | 新增家具 | 设计意图 |
| --- | ---: | --- | --- |
| old-home | 18 件原有家具 | 无 | 旧家布局，作为迁移源 |
| new-home-a | 18 / 18 | N01 折叠备餐推车 | 延续日常；沿用餐桌、独立客餐区 |
| new-home-b | 17 / 18 | N02 双翼折叠餐桌、N04 梯凳两用椅 | 会客区转向；收起餐桌可腾出空间 |
| new-home-c | 18 / 18 | N03 壁挂折叠书桌、N04 梯凳两用椅 | 旧书桌移入公共区，次卧新增第二工作位 |

B 方案未带入 F04 旧餐桌；明确列为留存/转赠，不计入沿用数量。配件（床品、台灯、植物、电视、笔记本）属于对应家具组合，计数单位为清单中的独立组合，不计固定厨卫设施。

## 文件

- `models/old-home.glb`：旧家完整场景。
- `models/new-home-{a,b,c}.glb`：新家三种完整场景，建筑结构一致。
- `models/{old,new}-home-shell.glb`：固定建筑、厨卫和部分软装地毯。
- `models/furniture/F01.glb` 至 `F18.glb`：旧家家具，局部原点位于地面中心附近。
- `models/furniture/N01.glb` 至 `N04.glb`：对应现有商品品类的新家具。
- `data/furniture.json`：名称、原有/新增、尺寸、现有商品 slug。
- `data/layouts.json`：每个场景中的家具 ID、x/z 坐标与 Y 轴旋转角度，以及沿用/新增/未带入清单。
- `previews/`：四个场景各一张立体图、一张由模型渲染的俯视图。
- `references/`：原始两张户型图，仅存档作为建模依据；网页不将它们当作实时平面图。
- `src/generate.mjs`：确定性建模脚本，全部材质、细节、建筑与布局都可编辑。
- `vendor/`：本地 Three.js 运行依赖与许可证；预览不依赖 CDN。

## 重新生成与 V2 接入

```sh
# 使用现有仓库的 three 依赖
node v2-home-models/src/generate.mjs
```

完整场景可以直接使用 Three.js 的 GLTFLoader 加载。也可加载一个建筑 shell，然后依据 `layouts.json` 复用 `models/furniture/<id>.glb`：

```js
const { scene } = await loader.loadAsync(`models/furniture/${item.id}.glb`);
scene.position.set(item.x, 0, item.z);
scene.rotation.y = THREE.MathUtils.degToRad(item.rotation);
```

坐标遵循原图：x 向右、z 向下；`dimensions` 数组为宽/深/高。GLB 节点 extras 保留 ID、来源、商品 slug 与可选中标志。`foldAxis` / `foldAngle` 定义折叠铰链。墙体的 `wall` extras 用于剖切，`upper` 标记可在剖切时隐藏的高处构件。预览器对静态同材质零件运行时合批，保留家具根节点和可动铰链，并只在结构状态改变时重绘阴影。

## 尺度与设计假设

依据图中房间位置、门洞、外轮廓和常见家具尺度重建，不是测绘或 CAD 精确复原。旧家外轮廓约 8.8 × 5.5m，入口有退台；新家约 8.4 × 6.15m，北侧有退台。图中旧家房间标注合计 44m²，新家各房间合计 48m²，而新家标题是约 45m²；界面保留标题的约 45m² 作为参考信息，不以它冒充精确测量。

主要家具以同一套几何、材质和尺寸在各场景重复使用。新增家具按现有 `lib/folding-products.ts` 的品类与主要尺寸制作概念模型，不是供应商认证产品 CAD。暖橡木、奶油亚麻、鼠尾草绿、少量黄铜形成统一风格；包含地板拼缝、软包、枕头、床毯、柜门拉手、窗框窗帘、书本、绿植、厨卫洁具等适度细节。

未进行施工尺度、门扇全行程、人机工学或无障碍规范认证。布局检测只覆盖保守的家具矩形占地；需要实测数据后才能用于真实采购和施工。
