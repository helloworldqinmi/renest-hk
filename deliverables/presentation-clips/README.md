# Presentation clips

These are earlier standalone feature clips. The [final submission deck](../README.md) includes its own five embedded clips.

Use clips 01–04 in sequence; clip 05 is an optional product demonstration. Every clip is H.264 MP4 at **1920 × 1080 / 60 fps**, without audio or added subtitle tracks. The website's own interface text remains visible.

The links below are downloads for local playback or insertion into presentation software. GitHub's file page may not preview the videos; use **Download raw file** if needed. Private-repository downloads require repository access.

| Clip | Duration | Demonstration |
| --- | --- | --- |
| [Download 01 — Furniture scan](01-furniture-scan.mp4?raw=true) | 22 s | Phone capture, point cloud, reconstructed surfaces and furniture inventory. |
| [Download 02 — Floor plan to 3D](02-floor-plan-to-3d.mp4?raw=true) | 14 s | Example blueprint, rising walls, doors and windows. |
| [Download 03 — Layout comparison](03-layout-comparison.mp4?raw=true) | 16 s | Familiar comforts, Room to gather and A place to focus. |
| [Download 04 — Layout editing](04-layout-editing.mp4?raw=true) | 15 s | Select the sofa, stage it, reposition it and return to 3D. |
| [Download 05 — Folding furniture](05-folding-furniture.mp4?raw=true) | 12 s | Fold and unfold a space-saving dining table. |

The clips were exported from the unsubtitled source materials used by the final-film production. Fast actions were slowed and selected opening/closing frames held for presentation. Clip 02 is cropped and centred to remove unused space, while retaining a 16:9 frame.

Scanning and reconstruction demonstrate the prototype's simulated capture and example geometry. Layout comparison, editing and folding show application interactions. Set playback to automatic or on click in the presentation software; pause at the end when discussing a result.

[Edit manifest](edit-manifest.json) records the historical source cuts. [Verification](verification.json) preserves the original production results with the delivery filenames updated. The original raw clips are local production inputs and are not included here.
